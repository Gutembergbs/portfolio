# Portfólio — Gutemberg Brito

Site pessoal de Gutemberg Brito, Engenheiro de Computação e desenvolvedor Full
Stack e Mobile. Reúne projetos e experiências em saúde digital, aplicativos e
automação de processos.

## Publicação

O site é estático e publicado pelo GitHub Pages:

- Site: <https://gutembergbs.github.io/portfolio/>
- Repositório: <https://github.com/Gutembergbs/portfolio>

O workflow em `.github/workflows/deploy-pages.yml` publica `index.html` e
`styles.css` após cada push para `main`. Configure **Settings → Pages → Source:
GitHub Actions** no repositório.
